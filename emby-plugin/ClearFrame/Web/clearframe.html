ClearFrame

Server side of the ClearFrame home screen for Samsung TVs. Pair each TV here, pick the Emby account it uses, and link Emby accounts to Seerr so requests from the TV are made by the right person.

TVs

Start pairing in ClearFrame on the TV and its code appears below. For one-press playback, ClearFrame needs to know which Emby app session belongs to the TV: open the Emby app on that TV once, press Refresh, then choose it under Emby app on this TV. If Emby uses the TV's hardware ID, it's matched automatically.

Seerr

The API key is under Seerr → Settings → General. It stays on this server and is never sent to TVs.

Account links

Sync links Seerr accounts that already sign in with Emby (auto), and suggests matches by username or email (dashed; press ✓ to confirm). Suggestions aren't used until confirmed. Link several Seerr accounts to one Emby account for a shared login, and the TV asks who's requesting.
